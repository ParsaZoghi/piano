# Keystage — research references

Thirty journal articles (2020 or later) on game-based learning, piano learning and
music-skill training. Every entry was verified against the Crossref registry on
2026-10-13 (title, authors, journal, year and DOI). The design notes are drawn from
titles and abstracts, not from a full-text reading, so treat them as design
motivation rather than as a claim about each paper's detailed findings.

## How the papers shaped the game

| Design decision in Keystage | Motivated by |
|-----------------------------|--------------|
| Short game-like lessons with points, streaks, stars and unlockable levels instead of drill sheets | [1], [2], [7], [9], [10] |
| Notes and rhythm taught as separate units before they are combined in songs | [1] (novices struggle with rhythm, melody and theory), [24], [25], [27] |
| Moving shapes travelling toward the key to be pressed (the note highway), plus a highlighted target key | [13], [14], [15], [21] |
| Staff notation shown next to the key and note name, with hints that fade (key → name → staff only) | [3], [6], [15], [28] |
| Immediate per-note feedback (Perfect / Good / Early / Late / Miss) and a targeted tip on the results screen | [1], [14], [22], [24] |
| "Listen first" demonstration before the learner plays | [29] (listen-then-play), [19] |
| Wait mode and adjustable practice speed, so difficulty can match skill | [23] (difficulty levels), [29] (flow), [30] (self-regulated practice) |
| Lesson keyboard limited to the keys the lesson needs; full 88 keys only in free play | [13], [23] (reducing load for beginners) |
| Works with whatever the learner has: typing keyboard, MIDI keyboard or a phone | [11] (avoiding dependence on MIDI hardware), [17], [19] |
| Automatic scoring of note and timing accuracy | [12], [22] |
